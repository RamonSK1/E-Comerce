# 🛒 E-Commerce — Vue.js + TypeScript

Projeto prático de e-commerce desenvolvido como parte do curso de FullStack do Curso de Programação FullStack TIC-HUB 12.

## 📌 Sobre o Projeto

Aplicação web de e-commerce construída com foco em boas práticas de frontend moderno. O projeto está em desenvolvimento ativo, com novas funcionalidades sendo adicionadas a cada atividade do curso.

## 🚀 Tecnologias Utilizadas

- **Vue.js** — framework progressivo para construção de interfaces
- **TypeScript** — tipagem estática para maior segurança e organização do código
- **HTML5 & CSS3** — estrutura e estilização das páginas
- **Git & GitHub** — versionamento e controle do código
